# Requested editorial and on-page SEO

Start with the actual offer, audience/market, provided business facts, existing
pages and search intent. Research current queries with suitable sources when
needed; distinguish measured demand from suggestions/autocomplete. Never
invent volume, testimonials, addresses, authors, prices or legal claims.

Map a distinct primary job/intent to a useful URL. Group related queries,
identify real overlap/cannibalisation and propose consolidation only with the
existing URL/migration owner. Avoid translated or country-swapped near-duplicate
pages without local value. A keyword map is an editorial proposal, not authority
to create every URL or change product claims.

Write unique readable titles and descriptions that match visible content and
the offer. Length estimates are editing aids, not search-engine acceptance
conditions; snippets may be rewritten. Use meaningful heading hierarchy, not
a rigid single-H1/character-count gate. Keep internal links useful to visitors,
with descriptive text and actual working destinations.

Structured data reflects supported page types and visible facts. Organization/
LocalBusiness, Article, Product/Offer or Breadcrumb types apply only when true.
FAQ/Q&A content alone does not guarantee rich-result eligibility. Refresh
current search-specific rules; never fabricate schema facts to pass a validator.

Return concrete page/theme→intent→proposed title/description/link changes with
evidence and uncertainties. Do not expand a requested text pass into forms,
deployment, visual redesign or four account integrations.
