# Доступы для копии проекта

Читать при проверке GitHub, настройке Composio или подключении сервера.
Это договоры разных каналов, а не инструкция копировать локальные credentials.
Факты о Cloud сверены 01.11.2026; перед изменением настроек сверяй актуальный
интерфейс и официальную документацию.

## GitHub

Проверь существующий доступ чтением известного файла выбранного repository/ref.
GitHub MCP, в том числе через Composio, выполняет API-операции в пределах своих
прав. Он не выдаёт автоматически credential для `git push` в VM. Если задача
требует отправки, используй уже работающий разрешённый канал проекта и проверь
точные branch/commit на remote после операции. Не проверяй запись созданием
лишнего commit, PR или файла. Подключай новый аккаунт только для конкретного
доказанного пробела и с соответствующим разрешением.

## Composio только в Cloud

Сохраняй локальные native MCP и plugins. Открой существующий Composio account и
проверь нужные connected apps, account identity и ограничения; не повторяй OAuth
из-за нескольких Active records. Active в панели означает сохранённое подключение,
но не успешное чтение API из выбранного Cloud-хоста.

Используй текущие [Composio Connect docs](https://docs.composio.dev/docs/composio-connect)
и наш [профиль Cloud](https://github.com/ArtemArzi/codex-agent-graphs/blob/main/docs/COMPOSIO-CLOUD.ru.md).
Для Connect endpoint `https://connect.composio.dev/mcp` header
`x-consumer-api-key` получает consumer key из Connect Agents/AI Clients.
Project API key относится к другому session contract; ключи не взаимозаменяемы.
Человек вводит нужный ключ только в защищённую форму поддерживаемого хоста.

Сначала установи, какой MCP-хост обслуживает ОСНОВНОГО Cloud-агента и какие
transport/auth он поддерживает. Запись `.codex/config.toml` в execution VM не
доказывает, что этот хост её прочитал. Отдельный вложенный Codex CLI также не
доказывает подключение основного агента. При отсутствии поддержанного способа
закончи независимую подготовку и назови незавершённую интеграцию.

В существующем профиле разрешены только `COMPOSIO_SEARCH_TOOLS` и
`COMPOSIO_GET_TOOL_SCHEMAS`. Это проверка поиска и схем; provider execution,
управление аккаунтами и workbench не включены. Для реального чтения GitHub/Drive
нужен поддержанный способ исполнения и отдельные права. Не расширяй allowlist
молча и не выдавай schemas-only PASS за готовый коннектор.

## Секреты и сеть Cloud

[Cloud environment configuration](https://learn.chatgpt.com/docs/environments/cloud-environments)
различает direct environment variables и network secrets. У network secret
процесс получает placeholder, а HTTPS proxy подставляет значение только для
разрешённых destinations на порту443. Хранилище Personal vault передаёт только
запрошенные средой имена; сохранение значения не доказывает его получение
внешним MCP-хостом. Согласуй тип секрета с фактическим потребителем.

Настраивай нужные package/API domains; доступность домена не даёт прав на API.
Не копируй секреты из локальных файлов и не выводи их для диагностики. Для
приватного пакета отдельно нужен разрешённый канал доставки и закрытая среда.

## Сервер только при необходимости

Прочитай runbook именно выбранного проекта и определись с host, identity,
нужной операцией и полномочиями. SSH необязателен для разработки по GitHub.
Доступ для проверки не разрешает production изменения или деплой.

Текущая Cloud документация описывает SSH/TCP через Tailscale VPN: IPv4
destination должен идти по разрешённому маршруту, клиент использует HTTP CONNECT
proxy `proxy:8088`; hostname сохраняется для proxy-side DNS. Для VPN auth key
нужны Reusable и Ephemeral. Отдельно нужны SSH identity, credentials и проверка
host key по проектному runbook. Network-secret substitution не передаёт SSH
ключ в TCP tunnel. Сетевой маршрут и успешная аутентификация проверяются отдельно.

Не копируй автоматически локальный SSH home, не отключай host-key checking и
не открывай общий доступ к production ради быстрого запуска. Подготовь отдельный
минимально достаточный доступ, если он нужен и разрешён. Сначала проверь
идентичность целевого сервера и согласованное чтение; остановись перед внешней
операцией, которой нет в поручении.
