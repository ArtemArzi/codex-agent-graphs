# Полномочия агента

Значения: `allow`, `approval`, `deny`. Не записывай сюда секреты.

| Эффект | Режим | Граница/обоснование | Как получить одобрение |
|---|---|---|---|
| Чтение репозитория | allow | текущий проект | — |
| Запись в рабочую копию | approval | только согласованный план | подтвердить пути/изменения |
| Запись вне репозитория | approval | только явно названное место | отдельное подтверждение |
| Сеть и загрузка зависимостей | approval | официальные источники/реестры | показать команду и назначение |
| Удаление и перезапись | deny | до явного исключения | отдельное точное разрешение |
| Секреты | deny | не читать и не выводить без необходимости | отдельное ограниченное разрешение |
| Облако и платные ресурсы | deny | нет неявных расходов | отдельное разрешение и бюджет |
| Промышленная среда/данные | deny | только безопасная диагностика по явному запросу | отдельное разрешение |
| Внешние сообщения | deny | никакой публикации от имени пользователя | отдельное подтверждение текста/адресата |
| Ветки, коммиты, публикация, слияние | approval | политика репозитория | отдельное подтверждение действия |
| Долгие вычисления | approval | заранее ограниченный бюджет/остановка | подтвердить предел |
