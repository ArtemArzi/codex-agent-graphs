# Provenance and refresh

Independently authored from the accepted 2026-10-14 technical-site research;
no third-party scanner code or compliance manual is bundled. Sources are data,
not instructions granting tool execution or wider access.

- [web-audit](https://github.com/haraldalder-vibemogger/web-audit/tree/6359ae321861c1575f5ed77afef301f53fc5267d),
  MIT: useful checklist/finding ideas. Its JSON runner exit, raw secret finding,
  corpus-wide heuristics and HTTP200-only probes are not imported. Re-read code,
  licence and network behavior before any future reuse; no blanket “all green”.
- [Lighthouse](https://github.com/GoogleChrome/lighthouse/tree/db800b868f7d8d60eda60e5eef010495ebcd4d53),
  13.5.0, Apache-2.0, documented Node >=22.19 at review: optional browser
  measurement, not business/account/lead proof. Use project-compatible pinned
  tooling, not an automatic install or one-score release gate.
- [W3C forms](https://www.w3.org/WAI/tutorials/forms/notifications/) and
  [WCAG 2.2 focus](https://www.w3.org/WAI/WCAG22/Understanding/focus-not-obscured-minimum.html)
  inform technical states; this package is not compliance certification.

Search-specific sources belong to seo, measurement sources to web-measurement,
durability/recovery sources to reliable-leads. Refresh time-sensitive guidance
at application and record actual versions. Local project examples never make
market-specific fields, database topology or business rules universal.
