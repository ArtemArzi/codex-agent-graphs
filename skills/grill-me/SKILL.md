# Grill Me

Use the available `grilling` skill in product-discovery mode. It owns question
rounds, dependency-aware follow-ups, use of existing answers and completion;
this entry starts no second interview or implementation workflow.

If grilling is unavailable, read the current project context, ask the next
consequential questions whose prerequisites are known, follow each answer and
record settled/open decisions with their existing owner. Keep rounds manageable
without limiting their total number. End on usable understanding of the requested
area; do not invent requirements or request universal final approval.

For agreed terms and durable decisions that need project documents, use the
available `grill-with-docs` combination within this same interview.
