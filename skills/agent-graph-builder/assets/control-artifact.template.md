# __GRAPH_ID__ control artifact

The work node writes `__WORK_ARTIFACT__`. It is a compact receipt for the current candidate, not a reasoning transcript or a second plan.

Define and validate:

- graph, run and mode identity;
- canonical input and baseline digests;
- selected skills, MCP and agent receipts;
- observable acceptance evidence;
- unresolved decisions and residual risks;
- exact completion fields required by `__COMPLETE_ARTIFACT__`.

The verifier must bind to the immutable work receipt and current candidate. Completion must recheck the candidate instead of trusting summaries.
