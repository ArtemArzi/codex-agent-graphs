# Original visual examples

Six PNG miniature compositions accompany the visual-directions method. Open only
the relevant alternatives with the current host's image-viewing capability.
These are authored examples, not screenshots of third-party sites and not a
fixed list of approved palettes. The runnable source is the repository's
products/interface-design/reference-gallery; it is not required at runtime.

Each PNG carries its rendering origin in metadata. provenance.json records exact
hashes and browser version. Scenery comes from the original generated fictional
scene documented in the landing demo. No brand's source photographs are bundled.
