# Visual directions and reference roles

Use when the visual choice is genuinely open. These are examples for seeing and
discussing a direction, not six templates or the only permitted aesthetics.
The user can supply another world, combine two deliberately, or delegate a choice.
Refinement inherits the current world and does not reopen this selection.

Six original miniature previews are bundled under `assets/visual-examples/` in
this skill. Open only the relevant two or three through the active host's image
viewer when alternatives matter. They show composition, density and type roles;
they are not fixed palettes to apply to every product. A missing image-viewing
tool does not justify pretending to have inspected them.

The repository also includes an original, runnable **reference gallery** at
`products/interface-design/reference-gallery/`. It is a product artifact, not a
runtime skill dependency and is not copied by skills-only installation. When it
is absent, the primary links and decision method below remain sufficient. The
gallery's miniature compositions are independently drawn examples, not screenshots
or reproductions of the named brands.

## How to choose

1. Identify the subject's actual objects, materials, setting, audience and assets.
2. Select two or three materially different directions only when the decision
   needs alternatives. Open current primary pages and inspect actual rendered
   output where the surface is available; a text scrape is not visual evidence.
3. Name what to borrow: composition, type scale, image role, density or a specific
   interaction. Name what stays with that reference, such as logos, claims,
   customer proof, fixed colors or navigation behavior.
4. Commit one primary direction. A secondary may solve one bounded need, such as
   route annotation, and must not overwrite the whole visual system.
5. Explain how the choice serves the product. If references cannot be loaded,
   state that gap, use the local examples/available assets and avoid claiming a
   visual match. Do not bypass access controls to obtain an inspiration page.

User taste is a profile, not an AI-authorship detector. Gradients, a neutral
background, a serif or a grid are contextual choices; stacking a different set
of fashionable defaults can create the same repetition. Apply the actual design
policy while designing. A clear new brief may explicitly revise that policy.

## Asset and decision contract

Record a reference's URL, date inspected, chosen trait, role and factual limits
in the existing surface brief. Do not download/rehost brand images or copy a
page wholesale without applicable rights. Prefer real project assets or original
generated imagery when a new subject image is needed; label fictional products
and scenes. Reuse [the visual contract](visual-contract.md) for concrete values.

The accompanying ЗА КРАЙ demo chooses exhibition-poster scale plus field-guide
annotation, with an original generated mineral landscape. It demonstrates one
selection rather than establishing a permanent expedition style for every site.
