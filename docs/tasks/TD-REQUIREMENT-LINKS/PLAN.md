## Основание и метод

Наблюдаемый пробел: Project Start уже описывает матрицу требования/риска и проверки,
Task Delivery передаёт project check IDs в Deployment, но не требует явной сверки
работ с основаниями в обе стороны и сохранения этой связи до заявления о выпуске.
Неверное допущение, которое предотвращает изменение: заполненный план и зелёный
набор проверок сами по себе означают выполнение всех принятых требований.

Внешний механизм: поиск требований без работ и работ без основания в
[GitHub Spec Kit analyze](https://github.com/github/spec-kit/blob/main/templates/commands/analyze.md),
проверен 2026-10-22, blob 7de2d28f0da797998e5e30d6323b7316a74e60ff.
Используется принцип сверки, без переноса файлов, команд, hooks или процесса
Spec Kit. Существующие quality/planning/testing/release owners сохраняются.

## План и критерии

| Требование пользователя | Изменение | Как проверить |
| --- | --- | --- |
| Добавить только вариант 2 | Уточнить существующие references и review templates | Diff не вводит eval-систему, exploratory QA или architecture linter |
| Использовать свои документы без спецификации | Ссылки на запрос, решения, quality, план/трекер; CANONICAL сохраняет одного владельца | Сценарий без spec.md; отсутствие нового реестра, схем и controller |
| Сверять полноту и обоснованность работ | План проверяется в обе стороны; техническая предпосылка допустима при понятном основании | Сценарий с пропущенной выгрузкой, неподтверждённой идеей и полезным SQLite-стендом |
| Сохранить связь до выпуска | Handoff передаёт основания, checks, результаты и пробелы | Сценарий отличает локальный mock от требуемой доставки и не принимает ложный итог |
| Сохранить рабочую основу | Изменены только инструкции/шаблоны и synthetic fixture | Существующие тесты, ссылки, diff --check, check_all и один block_reviewer |

Root выполняет ограниченную правку в native skill-only. Новые подсистемы и
внешние бизнес-эффекты отсутствуют; целостная plan/result пара не требуется.
Один read-only block_reviewer оценивает результат и учебный случай. Проверка
смысла не заменяется поиском ключевых слов. Synthetic evidence не доказывает
будущее поведение всех агентов и не является реальным деплоем.

Откат источников: отдельный обратный коммит после публикации; до неё кандидат
изолирован. Установка в рамках ранее согласованного обновления ограничена тремя
изменёнными skills с preimage, backup и readback.
