# Координация самостоятельных чатов

`chat-coordination` помогает заметить, когда две задачи пользователя затрагивают
общие файлы, API, БД, сервер, браузер или другой изменяемый ресурс. Он предлагает
независимую работу, исследование, изоляцию либо очередность. Каждый чат сохраняет
своё поручение и план. Software Factory управляет помощниками одной задачи.

Навык вызывается по ситуации из общих правил, Task Delivery, Project Start,
Software Factory, Deployment и Product Care. Ясная изолированная правка не требует
обхода чатов. Если инструменты связи недоступны, агент продолжает разрешённую
локальную работу и сообщает предел видимости.

Для сообщений используется фактическое прямое разрешение человека на нужный
чат/область; установка навыка такого разрешения не создаёт. Новые пользовательские
чаты и постоянное фоновое наблюдение автоматически не запускаются. Договорённость
или подтверждение сообщения не заменяют защиту записи в общий ресурс.

Пример запроса:

> $chat-coordination Проверь пересечение текущей задачи с известной работой
> соседнего чата. Сохрани их поручения, сравни реальные ресурсы и выбери, что
> можно делать независимо, а где нужен факт, общий контракт или очередность.
