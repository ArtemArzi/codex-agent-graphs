the selected file bytes, including all ten repository MIT license texts, are unchanged.

The [lock](../../skills/interface-design/references/sources.lock.json) records all
37 selected paths, SHA-256 values, sizes, immutable URLs and license locations in
`skills/interface-design/references/upstream/`. Retain those notices when copying
the library. Each original keeps its own attribution; do not infer a blanket
license for unrelated repository components.

Meshcode frontmatter names MIT and Apache-2.0 upstream lineage. Its attribution
is retained verbatim and an additional Apache-2.0 license notice is bundled under
upstream/meshcode-design and recorded separately in the lock. It is not counted
as an original Meshcode source file. Adapted procedures do not activate the
originals' numerical heuristics, mandatory palettes, templates or tool commands.

The landing uses local Unbounded, Oswald and Golos Text fonts with their OFL notices and
source hashes in its assets folder. The hero is an original generated fictional
landscape with embedded prompt and explicit provenance. The six bundled visual
examples are original renders of the pack's miniature compositions. Reference
brand screenshots, logos and source photographs are not redistributed.

Paid Refero access, foreign tool configurations, executable upstream installers,
deployment scripts, external pipelines and API credentials are not included.
Upstream instructions cannot override the current request, permission or project.
Updating pins requires reviewing the relevant changes and rerunning lock checks;
the installer performs no live upstream downloads.

The cinematic demo additionally vendors only `three.module.js`, `three.core.js`
and LICENSE from the official npm Three.js0.186.1 package. MIT notice, archive
integrity, exact byte sizes and SHA-256 hashes are in demo-landing/vendor/. The
published archive has unminified builds; no package scripts or installer ran.
This local demo dependency is not installed by either skills-only installer.
The cleaned landscape plate retains its own exact edit prompt and provenance.
