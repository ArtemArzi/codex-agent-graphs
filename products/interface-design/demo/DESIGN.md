# Operate: спокойная рабочая поверхность

Источник решений: локальные interface-design design-policy/methods и PRODUCT.
Единый визуальный владелец: эта адаптация. Другие design plugins не запускались.

Поверхность #e8e9e6, рабочая область #f3f4f1, текст #20312e, основной action
#244f46. Состояния имеют текст, цвет только усиливает его. Семейство Segoe UI,
Arial, sans-serif, шкала12/14/16/22/30px, системный шрифт уместен для Operate.
Таблица и типографика дают структуру, радиус4px у контролов; без feature cards,
пилюль, градиентов, теней, Lucide, декоративного motion и белого canvas.

Desktop: читаемый список и панель выбранного объекта, одна главная задача.
Mobile: список и подробности последовательно, колонки перестраиваются,
основные действия имеют достаточную область нажатия. Кнопка выбора записи
доступна клавиатурой, фокус видим. Статусы, ошибки и сохранение объявляются.
Технические учебные переключатели находятся отдельно под рабочей поверхностью.
