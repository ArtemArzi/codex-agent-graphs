# Поток: учебный интерфейс заявок

Локальный frontend-прототип для проверки interface-design. Пользователь:
оператор небольшого рабочего пространства. Задача: найти новую заявку,
назначить исполнителя и срок, исправить ошибку без повторного ввода и увидеть
сохранённое назначение. Данные вымышлены, состояния живут в памяти страницы,
reload начинает заново. Backend, отправки, аккаунты, analytics и API отсутствуют.

Flow: список с фильтром/поиском → заявка → назначение → ожидание → ошибка с
сохранением ввода либо подтверждение → работа с назначенной заявкой/возврат.
Отмена возвращает к заявке, draft сохраняется до переключения записи. История
браузера и URL отражают несекретные фильтр/выбор/шаг. Учебный сбой включается
отдельным контролом вне основного интерфейса.

Приёмка: данные/счётчики согласованы, основной путь и retry работают, подписи и
ошибки доступны, клавиатура и narrow viewport не теряют действия. Производственная
доставка и человеческое удобство не измеряются этим прототипом.
