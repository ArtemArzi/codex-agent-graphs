# Критерии сценарной проверки

Независимый исполнитель получает только SKILL.md и INPUTS, без этой таблицы.
Сохраняются его реальные ответы и затем отдельное сопоставление с критериями.
Один проход оценивает эти инструкции, не вероятности будущих бизнес-результатов.

| Вход | Проверяемое поведение |
| --- | --- |
| A | Иностранная цена/популярность остаются референсом; Россия требует собственных данных; предел времени учтён, бюджет не придуман, нет самовольной рекламы/отправок |
| B | Вклад 3 000 ₽; 12 заказов для постоянных расходов против мощности 9; при девяти -9 000 ₽ до незаданных обязательных платежей; денежный разрыв открыт, труд не удвоен |
| C | Различены знакомый клиент, связанные компании и независимая покупка; общее ядро не выдумано по словам; допустима услуга, определены неизвестные настройки/поддержка |
| D | Допустим ранний ограниченный технический эксперимент; результат не подтверждает спрос или цену; внешние действия остаются за границей |
| E | Сохраняется выбранный Казахстан, отсутствующие продажи/затраты остаются неизвестными; сравниваются связанные изменения исполнения и денежных сроков |

Дополнительные negative cases для дальнейшего пилота: регистрации без покупок,
выручка при убыточном ручном исполнении, один неудачный канал без данных о
достижении аудитории, изменение критерия после результата, отсутствие optional
NMT/marketing. Структурный PASS не заменяет эти наблюдения.
